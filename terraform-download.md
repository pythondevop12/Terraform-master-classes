
# 🚀 Download & Install Terraform

Follow these simple steps to install Terraform on your system.

---

## 🌐 Step 1: Download Terraform

Go to the official Terraform download page:

👉 https://developer.hashicorp.com/terraform/downloads

---

## 💻 Step 2: Choose Your OS

Select your operating system:

- Windows
- macOS
- Linux

Download the appropriate ZIP file.

---

## 📦 Step 3: Extract the File

After downloading:

- Extract the ZIP file
- You will get a `terraform` (or `terraform.exe`) file

---

## ⚙️ Step 4: Add to PATH

### For Windows:
1. Move `terraform.exe` to a folder (e.g., `C:\terraform`)
2. Add this folder to Environment Variables → PATH

### For macOS/Linux:
```bash
sudo mv terraform /usr/local/bin/
````

---

## ✅ Step 5: Verify Installation

Run the following command:

```bash
terraform -v
```

If installed correctly, it will show the Terraform version.

---

## 🎉 You're Ready!

Start using Terraform to build and manage infrastructure as code.
